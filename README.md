# 🎓 Smart Campus Management System

### A Smarter Way to Manage Campus Services

Smart Campus is a Flutter-based campus management application designed to bring student services and administrative operations together in one platform.

The application provides dedicated student and administrator modules for accessing campus services, managing facilities, and organizing booking-related activities.

---

## 📌 Project Overview

Smart Campus aims to simplify campus service management through a centralized digital platform. It organizes student-facing services and administrative features into separate modules, providing a foundation for a more connected campus experience.

## 🎯 Objectives

- Centralize campus services in one application.
- Provide separate interfaces for students and administrators.
- Organize transportation, fee, and facility-related services.
- Simplify access to campus information.
- Support future enhancements for digital campus management.

## 🚀 Getting Started

### Prerequisites

Before running the project, install:

- Flutter SDK
- Visual Studio Code or Android Studio
- An Android emulator, physical device, or configured browser

Verify your Flutter installation:

```bash
flutter doctor
```

### Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/logeshwaris19/Smart-Campus.git
```

**Step 2: Navigate to the application directory**

```bash
cd Smart-Campus/flutter_application_1
```

**Step 3: Install dependencies**

```bash
flutter pub get
```

**Step 4: Check available devices**

```bash
flutter devices
```

**Step 5: Run the application**

```bash
flutter run
```

To run on Chrome, if web support is configured:

```bash
flutter run -d chrome
```

**Step 6: Run tests**

```bash
flutter test
```
